CULTURA TLAXCALA — guía web

1. Descomprime el ZIP.
2. Abre index.html en tu navegador para probarlo.
3. En assets/logos están los logos que ya me pasaste.
4. Agrega los otros 6 logos con estos nombres:
   - fansimioteca.jpg
   - galeria-bilulu.jpg
   - centro-de-las-artes.jpg
   - centro-cultural-la-libertad.jpg
   - centro-cultural-huamantla.jpg
   - galeria-del-agua.jpg
5. Si son PNG, puedes usar .png, pero cambia también el nombre de "image" correspondiente en js/app.js.
6. Para cada lugar, cambia maps:"" por su enlace de Google Maps.
7. Cambia description y responsible con los datos reales de tu documento.
8. Para fotos adicionales, mételas en assets/fotos/ y después podemos añadir galerías.
